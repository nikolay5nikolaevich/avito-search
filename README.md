# Avito — автовыкладка, аналитика спроса и рассылка

Локальный сервис для продавца на Авито. Работает на своей машине, через живой
браузер Chrome — никаких серверов и облаков. Один веб-интерфейс, пять разделов.

| Раздел | Что делает |
| --- | --- |
| **Аналитика спроса** (`/workspace`) | Парсит выдачу по 10 городам, считает средние просмотры в день, показывает топ-3 объявления и отдаёт CSV. Результат кэшируется на 24 часа. |
| **Автовыкладка** (`/draft`) | По одной форме готовит N уникальных вариантов объявления (текст + фото) и публикует их на Авито подряд. |
| **Рассылка** (`/outreach`) | Собирает продавцов из выдачи и пишет им в чат Авито. |
| **Рассылка IT** (`/it-outreach`) | Ищет сайты компаний в открытых данных и показывает опубликованные рабочие email. Письма не отправляет. |
| **Агенты** (`/agents`) | Сборщик статистики по своим объявлениям через API Авито и Стратег, который формулирует гипотезы по накопленным цифрам. |

---

## Публикация реальная и платная

Автовыкладка не делает черновиков — она проходит весь путь до отправки на
модерацию, включая экран стоимости просмотра. **Каждый запуск тратит деньги.**

Поэтому сценарий устроен пугливо: неизвестная подпись кнопки, незнакомая
платная услуга или отсутствие нужной цены на шкале — остановка пакета, а не
догадка. Финансовые клики никогда не повторяются при ретраях. Это защита, а не
баг.

Возобновление с середины пакета есть: после остановки на экране появляется
кнопка «Продолжить», которая пропускает уже созданные объявления и не платит
за них второй раз. Незавершённую задачу закрывают отдельной кнопкой «Закрыть
задачу» — новый запуск публикации её не заменяет молча, чтобы не получить
дубль уже отправленного.

## Быстрый старт

Windows, PowerShell. Нужен Python 3.11+ и Node.js.

**1. Скачать проект**

```powershell
git clone https://github.com/nikolay5nikolaevich/avito-search.git
cd avito-search
```

**2. Поставить зависимости Python**

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Если PowerShell ругается на политику выполнения — один раз выполни
`Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser`
и повтори активацию.

**3. Собрать интерфейс**

```powershell
cd frontend
npm install
npm run build
cd ..
```

**4. Запустить Chrome, в который будет ходить сервис**

```powershell
.\start-chrome.bat
```

Откроется обычный Chrome. Зайди в нём на avito.ru под своим аккаунтом и
**оставь одну вкладку** — лишние вкладки подвешивают подключение.

**5. Запустить сервис**

```powershell
python backend/app.py
```

Открой `http://localhost:7777`.

### Рассылка IT

После запуска сервиса открой `http://localhost:7777/it-outreach`, укажи число
сайтов (от 1 до 100) и нажми «Найти компании». Источник — бесплатные открытые
данные OpenStreetMap, поэтому список неполный; сайты, которые отрисовывают
контакты только JavaScript, могут не дать email. Сервис лишь собирает уже
опубликованные адреса: писем, Gmail и отправки сообщений в этом разделе нет.

### Почему именно живой Chrome

Авито банит любой браузер, запущенный Playwright'ом. Поэтому сервис не поднимает
свой браузер, а подключается по протоколу CDP к настоящему Chrome, который ты
открыл руками и где уже залогинен.

### Переменные окружения

Кладутся в `.env` в корне проекта.

| Переменная | Зачем |
| --- | --- |
| `AVITO_CDP_URL` | Адрес отладочного порта Chrome. При проблемах с IPv6 — `http://127.0.0.1:9222`. |
| `AVITO_MAX_ITEMS` | Сколько объявлений разбирать на город в аналитике (по умолчанию 150). |
| `AVITO_CLIENT_ID`, `AVITO_CLIENT_SECRET` | Ключи API Авито для Сборщика статистики. |

## Структура проекта

```
backend/     сервер и вся логика
frontend/    интерфейс на React, собирается в dist/ и раздаётся сервером
tests/       smoke-прогоны и точечные проверки рискованных мест
docs/        разборы прогонов, спеки, брифы интеграций
debug/       скрипты разведки живых страниц Авито и снятые дампы
n8n/         готовые воркфлоу автоответчика
```

### Backend

| Файл | Что внутри |
| --- | --- |
| `app.py` | Сервер FastAPI: все HTTP-эндпоинты и раздача собранного интерфейса. |
| `publisher.py` | Весь живой сценарий публикации: форма, подсказки, фото, цена, отказ от услуг. |
| `preparation.py` | Готовит N вариантов объявления из одной формы. |
| `text_variation.py`, `photo_variation.py` | Уникализация текста и фото. Без ИИ: текст дословный, различает артикул; фото — небольшой зум. |
| `category_profiles.py` | Профили категорий: какие поля и размерные сетки у пиджаков, кроссовок, жилетов и футболок. |
| `avito_publish_selectors.py` | Селекторы формы публикации. |
| `avito_selectors.py` | Селекторы страницы выдачи. Не путать с предыдущим. |
| `parser.py`, `analytics.py`, `cities.py`, `filters.py`, `cache.py` | Аналитика спроса: сбор, подсчёт метрик, справочник городов, кэш. |
| `outreach.py`, `outreach_store.py` | Рассылка продавцам и её история. |
| `agents_registry.py`, `journal.py`, `stats_collector.py`, `strategist.py` | Реестр агентов, общий журнал событий, сбор статистики и генерация гипотез. |
| `browser.py` | Подключение к Chrome по CDP. |
| `diag.py` | Диагностика: снимает страницу и складывает артефакты в `debug/`. |
| `publish_state.py`, `address_generator.py`, `env_file.py` | Состояние задачи публикации, генерация адресов, чтение `.env`. |

### Frontend

| Файл | Что внутри |
| --- | --- |
| `src/pages/WorkspacePage.jsx` | Аналитика спроса: запрос, прогресс, таблица по городам, выгрузка CSV. |
| `src/pages/DraftPage.jsx` | Форма объявления, предпросмотр вариантов и запуск публикации. |
| `src/pages/OutreachPage.jsx` | Сбор продавцов и отправка сообщений. |
| `src/pages/AgentsPage.jsx` | Статистика объявлений, журнал событий, гипотезы Стратега. |
| `src/lib/` | Работа с API и чистые функции, на которые есть тесты. |

## Тесты

```powershell
# Python: точечные проверки
.venv\Scripts\Activate.ps1
python -m pytest tests

# Smoke-прогоны (требуют запущенного сервера)
python tests/smoke_test.py
python tests/prepare_smoke_test.py
python tests/publish_smoke_test.py

# Frontend
cd frontend
npm test
```

Playwright держим на версии **1.60.0**: на 1.62 драйвер валит publish-smoke.

## Документация

- `docs/reports/` — разборы боевых прогонов и аудиты кода. Лучший источник по
  реальному поведению Авито — `2026-08-16-publication-errors.md`.
- `docs/reports/publish-error-registry.md` — живой реестр сбоев публикации:
  симптом, причина, лечение.
- `docs/specs/` — спеки подсистем: надёжная автопубликация, реестр агентов.
- `docs/integrations/` — автоответчик на n8n: бриф и план работ.
- `docs/assets/avito-form/` — скриншоты формы публикации, по ним сняты селекторы.
