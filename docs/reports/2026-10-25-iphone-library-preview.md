# Общий текст iPhone и порядок фото до подготовки

## Результат

По уточнению пользователя от 25.10.2026 общий эталон хранится в
`library/iphone/description/iphone.txt`. Он подходит всем поддерживаемым моделям:
подставляются модель, память, цвет и SIM, если соответствующие маркеры есть
в тексте. В пользовательском эталоне используются модель, память и SIM.
Адрес оставлен дословно, включая `@@@@`, код `А3257` убран по согласованию.
Общая папка требует ровно один корректный UTF-8 `.txt`. Старые описания по
моделям читаются при отсутствии общей папки.

Основная форма показывает фото выбранного пака до подготовки. Стрелки и
перетаскивание меняют порядок, первое фото главное. Случайный пак выбирается
до показа фото и фиксируется в форме. Обновление страницы сохраняет пак и порядок.
Исчезновение выбранного пака блокирует подготовку до явного выбора.

`prepare` получает выбранный пак и точную перестановку имён его фото,
проверяет отсутствие повторов/посторонних имён и копирует фото в нужном порядке.
Порядок и текст сохраняются вместе с подготовкой. Превью отдаётся отдельным
JPEG endpoint, включая преобразование HEIC; проверяются Host, Origin и пути
внутри библиотеки. Публикация остаётся отдельным действием.

## Файлы

- `backend/iphone_library.py`: общий эталон, каталог имён фото, порядок, JPEG-превью.
- `backend/app.py`: endpoint превью и поле `photo_order` в подготовке.
- `frontend/src/lib/iphoneLibrary.js`: выбор/фиксация пака, порядок, URL и проверки.
- `frontend/src/lib/publish.js`: передача выбранного пака и JSON-порядка.
- `frontend/src/lib/draftPersistence.js`: проверка сохранённого массива имён фото.
- `frontend/src/pages/DraftPage.jsx`, `frontend/src/styles.css`: превью и управление.
- `.gitignore`: вся локальная `library/` исключена из Git.
- `docs/iphone-library.md`, `docs/specs/iphone-library-mvp.md`: новые требования.
- Новые тесты: `tests/test_iphone_library_shared.py`,
  `tests/test_iphone_library_preview_ui.py`,
  `frontend/src/lib/iphoneLibraryPreview.test.mjs`.
- Прежние `tests/test_iphone_library_ui.py`, `tests/test_iphone_sim_choice.py`:
  исправлены настройки тестового браузера, тестовый Origin и устаревшая подпись
  кнопки; функциональные проверки сохранены.

Локально скопированы шесть пользовательских JPEG в
`library/iphone/iPhone 17 Pro Max/1024 GB/Основной/`.
Исходная папка `library/17pro max 1tb/` сохранена. Текст и фото не входят в Git.

## Проверки

Из корня проекта:

```powershell
.venv/Scripts/python.exe -m unittest discover -s tests -p 'test_iphone_*.py'
.venv/Scripts/python.exe -m unittest discover -s tests -p test_prepare_description_newlines.py
```

Результат: 59 тестов iPhone и 6 тестов переносов строк прошли.
Браузерные проверки выполнялись на системном Chrome headless, если bundled
Chromium Playwright отсутствовал. Проверка новой основной формы также повторно
прошла после финальной сборки: 1 passed. Внешняя сеть браузера заблокирована,
публикация заглушена, рабочие данные заменены временными каталогами.

В `frontend/`:

```powershell
npm test
npm run build
```

Результат: 68 passed; сборка Vite успешна. `git diff --check` без ошибок.

Отдельная подготовка на шести реальных пользовательских фотографиях и общем
эталоне в изолированном временном каталоге: `done`, два черновика по шесть фото,
адрес сохранён. Публикация на Авито и живой выбор SIM не запускались.
