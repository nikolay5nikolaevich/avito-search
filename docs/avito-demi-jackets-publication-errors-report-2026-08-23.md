## Встреченные ошибки

### 1. Ложная ошибка «селектор превью не найден»

**Где:** `upload_photos`, объявление №1, до платных переходов.

**Причина:** код проверял каждый кандидат селектора превью только один раз.
Рабочий селектор `[class*='uploader'] img` проверялся в первые пять секунд,
когда React ещё не создал превью. Затем селектор больше не перечитывался,
а код ждал вслепую и завершался ошибкой.

**Исправление:** добавлен циклический опрос всех кандидатов до общего таймаута.
Успех подтверждается только при количестве превью не меньше количества файлов.
На успехе и ошибке сохраняются сетевой и DOM-дампы.

**Статус:** решено. Живая разведка подтвердила элементы
`preview(...)/image` и ответы загрузки HTTP 200. После исправления все 15
отправленных объявлений успешно прошли загрузку девяти фотографий.

**Регрессия:** `tests/test_photo_preview_wait.py`.

### 2. Экран стоимости просмотра один раз не отрисовался

**Где:** одно из объявлений возобновлённого прогона.

**Причина:** задержка React после перехода на экран стоимости.

**Обработка:** существующая защита один раз перезагрузила пустой экран,
после чего заново проверила контекст и продолжила.

**Статус:** решено автоматически; объявление отправлено, повторного
финансового клика не было.

### 3. Backend не запустился через `.venv`

**Где:** перезапуск после исправления фото.

**Причина:** `.venv` ссылается на отсутствующий Microsoft Store Python 3.11.

**Обработка:** backend успешно запущен системным Python 3.12, тесты и живой
прогон прошли на нём.

**Статус:** есть рабочий обход. Саму `.venv` нужно пересоздать отдельно,
если она снова понадобится.

### 4. Встроенный браузерный плагин диагностики не инициализировался

**Причина:** среда отклонила внутренний файл плагина как недоверенный путь.

**Обработка:** использован штатный CDP-механизм проекта и живой Chrome,
через который работает сам `publisher.py`.

**Статус:** на публикацию не влияет; проблема плагина не исправлялась.
