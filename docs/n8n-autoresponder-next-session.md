# Автоответчик Авито — план работ

Бриф проекта: `n8n-avito-autoresponder-brief.md`.
Воркфлоу Этапа 1: `n8n/avito-autoresponder-stage1.json`.

Обновлено 27.08.2026 по итогам живой проверки API.

## Что уже проверено живьём (27.08.2026)

- `client_id` / `client_secret` получены на avito.ru/professionals/api — **работают**.
- `POST https://api.avito.ru/token` (form-urlencoded, client_credentials) —
  токен приходит. **Без слэша в конце**: со слэшем это старый GET-обработчик,
  он отвечает `invalid_request`.
- `GET /core/v1/accounts/self` — отдаёт профиль.
- `GET /messenger/v2/accounts/{id}/chats?unread_only=true` — **отдаёт чаты**.
  Значит подписка «Максимальный» получению чатов не мешает.
- Все три адреса в воркфлоу подтверждены, версии путей верные.

**Главное ограничение:** api.avito.ru не отвечает на запросы с зарубежных IP.
n8n Cloud (серверы за границей) получает `unauthorized_client` с теми же
ключами, которые с локальной машины работают. Отсюда — n8n только локальный.

## Этап 1. Только чтение — ЗАПУЩЕН 27.08.2026

Локальный n8n в Docker, сообщение из Авито долетает в Telegram.

Грабли, вылезшие при запуске:
- `$('Конфиг').first().json.telegram_bot_token` в ноде «В телегу» **не резолвился**
  (пустой URL → 404 от Telegram). Лечение: токен и chat_id вписаны в ноду
  напрямую как Fixed. Причина не найдена, к выражению не возвращаться.
- В `jsCode` внутри JSON перенос строки пишется `\n`, иначе при импорте
  строка рвётся пополам и нода падает с `Invalid or unexpected token`.

Бот ничего не отвечает, пересылает входящие в Telegram.

1. Docker Desktop → `docker pull docker.n8n.io/n8nio/n8n`
   (при недоступности реестра — с VPN; на работу бота это не влияет).
2. VPN выключить. `docker run -d --name n8n --restart unless-stopped -p 5678:5678
   -v n8n_data:/home/node/.n8n -e GENERIC_TIMEZONE=Europe/Moscow
   -e TZ=Europe/Moscow docker.n8n.io/n8nio/n8n`
3. `http://localhost:5678` → локальная учётка → импорт воркфлоу.
4. Нода «Конфиг» — 4 значения. Больше нигде ничего.
5. Test step на «Токен Авито» → должен прийти `access_token`.
6. Прогон всей цепочки → сообщение долетает в Telegram.
7. Publish. Интервал опроса локально не ограничен, лимита выполнений нет.

Дальше неделя без вмешательства: копятся реальные вопросы покупателей.
Белый список тем для автоответа собирается **из них**, не из головы.

## Этап 2. Черновики с кнопкой

Добавить после «Только новые»:
- запрос истории диалога и карточки объявления;
- ноду Claude: классификация (типовой / горячий / мусор) + черновик ответа;
- отправку в Telegram с кнопками «отправить» / «отвечу сам»;
- webhook-приёмник нажатий → `POST` сообщения в чат Авито.

Правило этапа целиком: **без нажатия кнопки покупателю не уходит ничего.**

Нужен Claude API key — это деньги, посчитать до старта.

  с объявлением.
- **Переход с опроса на вебхуки Авито** (`/messenger/v3/webhook`): выполнение

  для этого нужен туннель (cloudflared / ngrok) — публичного адреса у него нет.

  сценария проверить заново.
