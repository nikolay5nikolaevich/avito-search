# Документация проекта

## `reports/` — что реально происходило

Разборы боевых прогонов и аудиты. Это главный источник правды по поведению
Авито: всё здесь написано по логам и дампам, а не по предположениям.

| Файл | О чём |
| --- | --- |
| `2026-10-21-draft-description-newlines.md` | Лишние пустые строки в черновиках: повторное преобразование CRLF в Windows, исправление четырёх записей описания, проверки. |
| `2026-08-16-publication-errors.md` | Прогон 17/17: полный разбор каждого сбоя. Самый полезный документ по Авито. |
| `2026-08-16-autopublish-blockers.md` | Что мешает пакету проходить без человека. |
| `2026-08-23-demi-jackets-errors.md` | Прогон по демисезонным курткам. |
| `2026-08-12-backend-audit.md` | Аудит бэкенда: найденные проблемы и их статус. |
| `publish-error-registry.md` | Живой реестр сбоев публикации: симптом → причина → лечение. Пополняется после каждого падения. |
| `2026-09-23-resume-audit.md` | Аудит checkpoint/resume публикации: держит ли механика возобновления от дублей и повторной оплаты, 51 находка с проверкой на опровержение. |
| `2026-09-27-publish-job-lifecycle.md` | Один пакет публикации за раз: межпроцессный lock, закрытие задачи, возраст checkpoint и контракт API. |
| `2026-09-27-job-finish-and-traces.md` | Финал пакета: следы пропущенных объявлений (item_id, шаг, адрес), «завершена с пропусками», стоп по повторному id, дамп и закрытие вкладки при живом драйвере, отмена и необработанные исключения. |
| `2026-09-27-resume-ui-texts-docs.md` | Баннер незавершённой публикации, кнопка «Закрыть задачу», тексты остановок без совета «перезапустить» — и синхронизация CLAUDE.md/AGENTS.md/README/реестра ошибок с тем, что resume есть. |
| `2026-10-20-iphone-publication-errors.md` | Публикация iPhone 6/6: скрытое состояние, обязательные свойства, восстановление первого черновика, resume и итоговые ID. |

| Файл | О чём |

## Инструкции

- [Библиотека iPhone](iphone-library.md): расположение фотопаков и шаблонов, обязательный SIM, подготовка и запуск.

## `integrations/` — внешние сервисы

Автоответчик покупателям на n8n: `n8n-autoresponder-brief.md` — что делаем,
`n8n-autoresponder-plan.md` — план и результаты живых проверок API.
Сами воркфлоу лежат в `n8n/` в корне проекта.

## `assets/avito-form/`

Скриншоты формы публикации Авито. По ним сняты селекторы в
`backend/avito_publish_selectors.py`.

## `_internal/`

Рабочая кухня: планы, дизайн-документы, брифы исполнителям и заметки сессий.
Не в git — это черновики процесса, а не документация проекта.
