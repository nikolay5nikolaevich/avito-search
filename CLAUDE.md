Дополнения для Claude Code. Всё общее — в `AGENTS.md` выше.

## Оркестрация
Главная сессия работает оркестратором. Делегирование не требует одобрения:
объяви строкой «→ агент: задача» и запускай. После каждого субагента — короткая
сводка пользователю по формату «Готово, когда» из `AGENTS.md`: он хочет видеть
работу агентов, но не останавливать её ради согласований.

Субагенты (`~/.claude/agents/`):
- `executor` (Sonnet) — механика по готовому брифу: правки, формы, тесты, конфиги.
- `deep-thinker` (Fable/Opus) — дорогая голова: дебаг CDP/Playwright, гонки,
  упавшие smoke, аудит денежного кода перед боевым прогоном.
- `codex-executor` / `codex-critic` — Codex через `codex exec`: исполнение брифа
  другой моделью и cross-model review готового диффа.

Субагент оправдан, когда задачи независимы и идут параллельно или нужен чистый
контекст; поиск по коду и правку в пару строк оркестратор делает сам.

## Скиллы и MCP
- `superpowers` — pipeline brainstorm → plan → subagent-driven development.
- `mattpocock-skills` — TDD, диагностика багов, code review, проверка плана,
  domain modeling, тексты для агентов.
- `frontend-design`, `webapp-testing` — интерфейс и его проверка в браузере.
- MCP `claude-in-chrome` — разведка живых страниц Авито в браузере пользователя,
  только когда он на РУ-IP.
- Делегирование идёт без шлюза одобрения, поэтому скилл `intent-gate` отключён.
